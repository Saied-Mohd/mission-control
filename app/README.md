# Mission Control — PWA

Static, no build step, vanilla ES modules, system fonts, no third-party requests. Served by `mc serve`
(local mode, `/api/*` available) or from GitHub Pages under any subpath (GitHub mode, talks to the
contents API of the private data repo). All URLs are relative (`./…`). Spec: `../docs/CONTRACT.md`.

## Structure

```
index.html              strict CSP meta, manifest, loads js/app.js
manifest.webmanifest    start_url/scope "./"
sw.js                   shell precache (bump VERSION per deploy), network-first HTML, cache-first assets,
                        never touches /api/ or api.github.com; push + notificationclick + badge
deck-frame.html         sandboxed deck host (see "Deck" below)
css/app.css             the whole design system (dark ops console, mobile-first)
icons/                  generated by ../scripts/make-icons.mjs (node scripts/make-icons.mjs)
js/
  crypto.js store.js model.js   shared with the CLI (do not change their APIs)
  app.js                boot → session flow → shell (sidebar / topbar / bottom tabs) → hash router,
                        badges, polling, palette + keyboard shortcuts, SW registration/messages
  session.js            mode detection, claim, GitHub connect, unlock/lock, recovery reset,
                        remember-device (non-extractable CryptoKeys in IndexedDB), idle auto-lock,
                        vault unlock (5-min relock), passphrase changes, updateVault() (keeps
                        vault-index in sync + audits)
  adapters.js           LocalAdapter (/api/file, header X-MC: 1) and GitHubAdapter (contents API,
                        blob fallback for >1 MB, 409/422 → ConflictError); emits `mc:net` for "syncing…"
  ui.js                 h(), icon(), toast, modal, confirm, ask, segmented, time helpers,
                        markdown-lite (DOM-built, http(s)/mailto links only), strength meter
  push.js               Web Push subscribe/remove/resubscribe → DOC.pushSubs; install prompt
  palette.js            Ctrl/Cmd+K command palette
  deck-frame.js         runs inside the deck iframe
  views/
    auth.js             claim, recovery code, connect, lock, forced reset, local-server-down
    common.js           shared view helpers (chips, git health, days-left, polling, pull-to-refresh)
    dashboard.js project.js approvals.js inbox.js radar.js vault.js activity.js deck.js settings.js
    brain.js            owned by another agent: export async function renderBrain(root, ctx)
```

## How views get `ctx`

The router renders each route into a fresh `<div class="view">` and calls
`render(root, ctx)` (built-in views) or `renderBrain(root, ctx)` (brain, imported dynamically; a
placeholder shows if it is missing). A view may return a cleanup function (timers, listeners); it
runs on the next navigation or on lock.

```js
ctx = {
  store, model, toast, nav, h, confirm, modal,   // the contract every view (incl. brain) can rely on
  ui, icon, md, crypto, session, mode, keys,      // extras
  params,            // e.g. { slug, tab } for #/p/<slug>/<tab>
  route, setHash,    // setHash(href): change the URL without re-rendering (project tabs)
  projects(),        // cached index summaries; setProjects(list) updates sidebar
  refreshCounts(),   // re-read approvals / inbox badges
  onCleanup(fn),
}
```

All mutations go through `model.js` with actor `'saied'`. Vault writes go through
`session.updateVault(fn, action, target)`, which re-encrypts the vault with the vault key, rewrites
`vault-index` and appends to the audit log.

## Security notes

- Decrypted data and raw keys live only in memory. localStorage holds: mode, `{owner, repo}`, the
  wrapped `keys.json`, the PAT encrypted with the data key (aad `pat`), auto-lock minutes and the
  push device id. IndexedDB holds non-extractable data/name keys only if "remember this device".
- On lock: modals closed, view cleanups run, Store keys nulled, vault key dropped, PAT dropped.
- Agent text is untrusted: everything is rendered via text nodes / the DOM-built markdown-lite.
- Clipboard copies of secrets are cleared after 30 s (best effort).

## Deck

The deck is rendered in `<iframe sandbox="allow-scripts" src="./deck-frame.html">` (opaque origin, no
access to the app). The HTML is handed over with `postMessage` and written with `document.write`.
A Blob URL or `srcdoc` would inherit the app's CSP (`script-src 'self'`) and block the deck's inline
scripts, so `deck-frame.html` intentionally has no CSP of its own. If `mc serve` adds a CSP *header*
to static files, exempt `/deck-frame.html` (and `/deck/`).

## Deploying

Bump `VERSION` in `sw.js` whenever any app file changes (static assets are cache-first). Clients see a
"new version ready → Reload" toast.
